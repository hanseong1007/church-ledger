# 교회·모임 금전출납부 (모바일 웹앱 · 여러 명 공유)

수입·지출을 적고, 영수증 사진을 붙이고, 달마다·해마다 결산을 뽑아 **A4로 인쇄하거나 PDF로 저장**하는 앱입니다.
`index.html` 파일 하나로 동작하며(외부 라이브러리 없음), 입력한 내용은 **구글 시트에 바로 저장되어 여러 기기·여러 사람이 같은 장부를 함께 씁니다.**

- 만든 날: 2026-11-21
- 참고: `documents/교회-금전출납부-샘플.xlsx` 의 계정과목·누계 방식을 그대로 따랐습니다.

---

## 1. 여는 방법

1. 주소를 엽니다: **https://hanseong1007.github.io/church-ledger/**
2. 브라우저 메뉴 → **홈 화면에 추가** 를 하면 앱처럼 전체 화면으로 열립니다.
   - 삼성 인터넷: 메뉴(≡) → 홈 화면에 추가
   - 크롬: ⋮ → 홈 화면에 추가
3. 주소만 같으면 **누가 어느 기기에서 열어도 같은 장부**가 보입니다.
   기록은 이 기기(localStorage)에 먼저 저장되고, 동시에 구글 시트로 전송됩니다.

## 2. 공유 데이터 (구글 시트)

- 데이터 그릇: 「교회 금전출납부 (공유 데이터)」 스프레드시트 (탭: `거래내역`, `설정`).
- 앱 화면 위 **☁️ 상태 줄**에 연결 상태가 보입니다. `☁️ 동기화 완료 (방금)` 이면 공유 중입니다.
- **🔄 새로고침** 을 누르면 다른 사람이 방금 넣은 내용을 즉시 받아옵니다.
  누르지 않아도 **20초마다**, 그리고 앱으로 돌아올 때마다 자동으로 받아옵니다.
- 입력·수정·삭제·설정 변경은 **곧바로 구글 시트에 저장**됩니다.
- 인터넷이 끊기면 `⚠️ 이 기기에 저장됨` 으로 표시되고, 연결되면 **자동으로 올라갑니다**.
- 전에 이 브라우저에만 있던 기록이 있으면, 처음 연결될 때 **자동으로 시트에 올라갑니다**(같은 id 는 최신 것만 남김).
- 서버 프로그램은 `apps-script/Code.gs` (구글 Apps Script 웹앱)입니다. 구글 시트 → `확장 프로그램` → `Apps Script` 에서 관리합니다.

> ⚠️ 지금 설정은 **비밀번호 없이 누구나 열 수 있는 공개 주소**입니다. 주소를 아는 사람은 장부를 읽고 고칠 수 있으니,
> 주소는 교회 관계자에게만 전달해 주세요. 필요하면 공유 비밀번호를 덧붙일 수 있습니다.

## 3. 처음에 한 번만 (권장)

**설정** 탭 → ① 교회·부서·모임 이름 ② 작성자(보고서에 표시) ③ **기초 이월금**(앱을 쓰기 시작한 시점의 잔액) → **저장**.
연습해 보려면 같은 화면의 **샘플 데이터 채우기**를 누르면 2026년 9~10월 예시 11건이 들어갑니다. **전체 초기화**로 지울 수 있습니다.

## 4. 탭 설명

### ① 장부
- 상단에 **현재 잔액**(기초 이월금 + 수입 − 지출)과 수입·지출 누계가 보입니다.
- **수입 기록 / 지출 기록** → 금액, 날짜, 항목, 적요, 결제·수단, **영수증 사진**을 넣고 저장.
- 항목에서 **＋ 직접 입력…** 을 고르면 새 계정과목이 만들어져 설정에 저장됩니다.
- 목록은 달마다 묶여 최신순으로 나오고, 줄마다 **그 시점의 잔액**이 함께 표시됩니다.
- 줄을 누르면 **수정/삭제**, 영수증 썸네일을 누르면 **크게 보기·사진 저장**.
- 위쪽 **전체 기간**에서 달을 고르거나, **항목·적요 검색**으로 찾을 수 있습니다.
- **장부 인쇄**로 전체 목록을 A4로 출력할 수 있습니다.

### ② 월간 보고서
- `‹ 2026년 11월 ›` 로 달을 넘기고 **이번 달** 버튼으로 오늘로 돌아옵니다.
- **전월 이월금 / 당월 수입 / 당월 지출 / 차월 이월금** 요약.
- **항목별 집계**(금액·비중 + 막대 그래프)와 **영수증 증빙 모아보기**.
- **A4 인쇄 / PDF 저장** → 인쇄 대화상자에서 프린터 또는 *PDF로 저장*을 고르면 됩니다.
  인쇄할 때는 메뉴·버튼이 빠지고 보고서 서식(작성자·확인자 서명란 포함)만 나옵니다.

### ③ 연간 보고서
- `‹ 2026년 ›` 로 해를 넘깁니다.
- **연초 이월금 / 연간 총 수입 / 연간 총 지출 / 연말 잔액** 요약.
- **월별 수입·지출 추이** 막대 그래프와 **1~12월 결산표**(월별 수지, 월말 잔액, 건수).
- **엑셀(CSV) 내보내기**: 이 해 또는 전체. 엑셀에서 바로 열리고 한글이 깨지지 않습니다(BOM 포함).
- **백업(JSON) 저장 / 복원**: 영수증 사진까지 통째로 백업합니다. 폰을 바꾸기 전에 꼭 저장하세요.

### ④ 설정
- 기본 정보(이름·작성자·기초 이월금).
- **수입/지출 항목 추가·이름 변경·삭제**. 이름을 바꾸면 지금까지의 기록에도 함께 반영됩니다.
  (기록에 쓰인 항목은 지우지 않도록 막아 두었습니다.)
- **저장 공간 사용량** 표시, 샘플 채우기, 전체 초기화.

## 5. 계산 방식

| 항목 | 계산 |
|---|---|
| 누계 잔액(각 줄) | 기초 이월금 + 그 날짜까지의 수입 − 지출 |
| 전월 이월금 | 기초 이월금 + 1월~전월까지의 수입 − 지출 (해가 바뀌어도 이어서 계산) |
| 차월 이월금 | 전월 이월금 + 당월 수입 − 당월 지출 |
| 월말 잔액(연간표) | 연초 이월금 + 1월~해당 월까지의 수입 − 지출 |

## 6. 영수증 사진

- **촬영**(카메라) 또는 **갤러리**에서 고릅니다.
- 자동으로 긴 변 960px 안축에서 JPEG로 줄입니다. 시트 한 칸(50,000자)에 들어가도록 **42,000자 이하**가 될 때까지 크기·압축률을 단계적으로 조정합니다(보통 25~40KB). 원본은 보관하지 않습니다.
- 썸네일을 누르면 크게 보고 **사진 저장**으로 내려받을 수 있습니다.
- 영수증은 구글 시트의 `receiptData` 칸에 함께 저장되어 다른 기기에서도 보입니다.

## 7. 데이터 보관 주의

- 기록의 본 저장소는 **구글 시트**이고, 이 기기 브라우저(localStorage)는 입력을 바로 잡아 두는 **임시 저장소**(약 5MB) 역할을 합니다.
- 브라우저 데이터를 지워도 구글 시트 내용은 그대로 남습니다. 다음에 열면 다시 받아옵니다.
- 영수증은 100장에 약 3MB 정도이므로, 설정의 사용량이 **65%를 넘으면 백업(JSON) 후 오래된 사진을 정리**하는 것이 좋습니다.
- 같은 기록을 동시에 고치면 **나중에 저장된 것**이 남습니다. 누가 무엇을 고쳤는지는 시트의 `author`·`updatedAt` 열로 확인할 수 있습니다.
- 내용을 통째로 되돌리고 싶을 때는 연간 탭의 **백업(JSON) 저장**을 먼저 해 두세요.
