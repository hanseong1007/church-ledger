# 덕신교회 부서업무 (/edu/)

주일학교·교육부서 통합 관리 웹앱입니다. 기존 금전출납부(`/`), 재정보고(`/ppt/`), 중보기도문(`/prayer/`), 포털(`/portal/`)과 분리된 별도 경로입니다.

- 주소: **https://hanseong1007.github.io/church-ledger/edu/**
- 안드로이드 앱: `덕신교회-부서업무.apk` (이 주소를 여는 웹뷰 → 웹앱만 다시 배포하면 앱도 그대로 최신)

## 구성
- `index.html` · `style.css` · `core.js` · `ui.js` · `features.js` · `extra.js` · `app.js` — 화면과 암호화·동기화 로직
  - `extra.js` — 자녀 연결, 교사 담임·권한 관리, 문자·카톡, 아동 명단 양식/업로드, 연간 출석부, 주일보고 반려
  - `ledger-report.js` — 회계 통계·항목별 조회·연말 결산/예산
  - `plansheet.js` — 월별계획안(한글 양식) 화면·인쇄·`.hwpx` 계획안 파싱·주일보고 연계
  - `talent.js` — 달란트 포상제(기준·적립·사용·대장·학부모 화면)
- `jszip.min.js` — 아주 예전 브라우저에서만 쓰는 예비 압축 해제 모듈 (보통은 브라우저 내장 `DecompressionStream` 사용)
- `manifest.json` · `sw.js` · `icons/` — 홈화면 추가(PWA) · 오프라인 캐시. `index.html` 에서 `navigator.serviceWorker.register('sw.js')` 로 등록합니다.
- `apps-script/Code.gs` — 구글 시트 동기화 API (Apps Script 웹앱)

## 1. 회원가입 · 승인 (2026-11-26 추가)
- 로그인 화면은 **아이디·비밀번호 + 로그인 + 회원가입 신청** 만 있습니다. 역할 체크박스는 없습니다(신청서 안으로 옮겼습니다).
- 신청서: 역할(목회자·교육부서담당·교사·학부모) · 이름 · 아이디 · 비밀번호 · 소속 부서 · 소속 반 · 자녀 이름.
- **바로 윗단계가 승인**해야 가입이 끝납니다: 목회자→관리자, 교육부서담당→목회자/관리자, 교사→교육부서담당, 학부모→담당 교사.
  - 승인 화면에서 승인자가 **부서·반·자녀를 바로잡아** 지정할 수 있습니다(신청서에는 반 이름만 적히기 때문).
  - 승인 전 로그인하면 “아직 승인 전입니다”, 반려되면 사유와 함께 안내가 뜨고 다시 신청할 수 있습니다.
- **열쇠(DEK) 전달 구조**: 신청할 때 신청자 기기에서 RSA-OAEP 2048 열쇠쌍을 만들어 **개인키는 자기 비밀번호(PBKDF2)로 감싸** 시트에 두고, **공개키만 신청서에** 담습니다. 승인자가 승인을 누르면 승인자의 자료 열쇠(DEK)를 신청자 공개키로 감싸 시트에 기록하고, 신청자가 **첫 로그인 때** 자기 비밀번호로 개인키를 풀어 DEK 를 얻은 뒤 곧바로 자기 비밀번호 봉인으로 바꿔 저장합니다. → 승인자는 신청자의 비밀번호를 몰라도 되고, 자료는 계속 종단간 암호화됩니다.
- 계정 시트의 `deleted` 칸을 상태로 씁니다: `''` 정상, `P` 가입 진행중, `R` 반려, `1` 삭제. (Apps Script 수정 없이 같은 시트를 그대로 씁니다.)

## 2. 월별계획안 + 한글(.hwpx) 자동 반영 (v5.0.4 개편)
교육부서가 쓰던 한글 **월계획안 양식 그대로** 한 장으로 입력·조회·인쇄합니다.
- **한 장의 구성** — ① 제목(`유치부 11월 교육계획` — 부서명+월 자동) ② `교사회의 기도 – 한마디 기도`
  ③ `기도해요`(여러 줄) ④ 주차별 표 **날짜 · 말씀 · 행사 · 담당자 · 기도 · 헌금위원 · 청소** (주일마다 한 줄)
  ⑤ `행사 진행`(날짜별 세부 진행) ⑥ `교사`(환경 구성 + `달란트 – 출석 3, 가정 공과 3, 암송 10, 전도 20`)
- **한글(.hwpx) 올리기** — `Contents/section*.xml` 의 표를 7칸 격자로 읽어
  - 한 칸에 여러 줄로 적힌 주차 값을 **줄마다 나눠** 각 주차 줄에 넣고(1줄짜리 칸은 모든 주에 같은 값),
  - `기도해요`·`행사 진행`·`교사` 칸을 각각 제자리에 담고, `달란트 – …` 의 숫자를 달란트 기준으로 뽑습니다.
  - 올린 뒤 **부서·담을 달·제목**을 확인하는 미리보기가 뜨고(파일 이름이 3월이어도 내용이 11월이면 11월로 읽습니다), 같은 달 계획안이 있으면 새로 담습니다. `달란트 기준도 함께 저장`(기본 켬).
  - 예전 간단 형식(날짜·행사·공과 3열) `.hwpx` 는 그대로 **계획 항목**으로 들어갑니다(호환 유지). 구버전 `.hwp`(CFB) 는 한글에서 `.hwpx` 로 저장하라고 안내합니다.
- **고치기** — `✏️ 수정`(전체 작성 창) 또는 표의 주차 줄을 눌러 **그 주만** 고칩니다. 주차 추가, 삭제, 인쇄(A4 세로, 한글 양식과 같은 표) 지원.
- **주일보고 연계** — 그 주일의 주차 줄에서 **말씀·행사·담당자·기도·헌금위원·청소·행사 진행**을 자동으로 채웁니다.
  말씀은 `예배 말씀`·`공과 내용`에, 나머지는 `특이사항`에(`행사: … 담당자: … 기도: … 헌금위원: … 청소: …` + 그 주 행사 진행) 들어가고, 보고서 화면·인쇄물에 `이 주 월별계획안` 표로 함께 나옵니다.
  손으로 고친 값은 `🗓️ 계획안 값을 보고서에 채우기` 를 다시 눌러도 덮어쓰지 않습니다(빈 칸만 채움).

## 3. 회계 (수입·지출·영수증)
- 교육부서담당·목회자·관리자만 보입니다.

## 5. 2026-11-26 2차 추가 (사용자 요청 11가지 + 목회자 화면 정리)
1. **자녀 연결** — `반·학생` 탭 맨 위 `👨‍👩‍👧 자녀 연결` 카드. 자녀가 연결되지 않은 학부모와 보호자 계정이 없는 아동을 보여 주고, 교사·교육부서담당이 바로 연결/변경합니다(학생의 `guardianUid` + 학부모 계정 목록을 함께 맞춤).
2. **교사 담임 지정** — 교육부서담당 화면에 `🧑‍🏫 교사·권한` 탭. 부서 교사의 담임 반을 지정·변경합니다(계정 기록을 그대로 고치며, 30초 안에 교사 기기에 반영).
3. **문자·카톡** — 학생 카드·출석 줄·알림장 미확인 보호자 목록에 `💬`. `sms:` 링크(번호·본문 미리 채움)와 카톡/공유(Web Share) · 내용 복사를 제공합니다.
4. **출결 알림** — 출석 화면 위 `출결 문자/카톡 바로 열기` 토글. 켜 두면 `출`을 누르면 "오늘 ○○ 학생 출석했습니다", `결`은 사유 입력 뒤 "○○ 학생이 오늘 결석하여 안부 여쭙습니다 (사유: …)"가 채워진 문자/공유 창이 열립니다(웹앱에서 실제 자동 발송은 통신사 API가 필요해 1탭 전송 방식).
5. **가입 생일 → 일정** — 회원가입 신청서에 생년월일. 승인될 때 소속 부서 일정에 `🎂 이름 생일`을 자동 등록합니다(월-일로 보관해 해마다 표시).
6. **계획표 → 일정** — 월별계획표 직접 등록·한글(.hwpx) 반영 항목을 `일정` 탭에도 자동 등록합니다(계획 ID로 중복 방지, 계획 수정·삭제 시 함께 갱신). 공과는 일정에 넣지 않습니다.
7. **아동 명단 양식** — `반·학생`에서 `명단 양식 다운로드(.csv)` / `작성한 명단 올리기(.csv·.xlsx)`. 반명·이름·생년월일·성별·보호자·연락처·메모. 없는 반은 자동 생성하고, 생일은 일정에 자동 등록. 기존 자료는 `🎂 생일 일정 맞추기`로 한 번에 맞출 수 있습니다.
8. **주일보고 반려** — 목회자가 `확인 완료`한 보고서도 사유를 적어 `반려(재작성 요청)`할 수 있고, 교육부서담당은 반려 사유를 보고 고쳐 다시 제출합니다.
9. **권한 위임** — `교사·권한`에서 교사별로 `일정 관리`·`회계 입력/관리`·`주일보고 작성`을 체크하면 해당 탭이 교사 화면에 열립니다(계정의 `grants`에 보관).
10. **연간 출석부** — `출석통계` → `📅 연간 출석부`: 그 해 1~12월 모든 주일을 열로, `반명·이름·생일·출·결·인` 표. 인쇄(A4 가로)와 CSV 내보내기.

- **적립** — ① 출석 화면에서 `출`을 누르면 `출석` 달란트가 저절로 붙고(끄기 가능), ② `달란트 → 적립(부여)` 에서 학생마다 항목 칩을 눌러 그 날 하루치를 담습니다. `출석 +3 / 가정 공과 +3 / 암송 +10 / 전도 +20` 단추로 반·부서 전체에게 한꺼번에 줄 수 있고, `➕` 로 기준 밖의 `기타` 달란트(이유 포함)도 줍니다.
- **사용·시상** — `🏅` 로 학생·날짜·점수·내용을 적어 차감합니다. 목록에서 지우면 잔액이 되돌아갑니다.
- **대장·내역** — 학생별 항목 횟수·적립·사용·잔액 표(`📒 대장·내역`), 학생을 누르면 전체 적립/사용 내역. `🖨 대장 인쇄`(A4)와 개인 `내역 인쇄`.
- **학부모** — 학부모 화면에 `🎁 달란트` 탭. 연결된 자녀의 연간 적립·사용·잔액, 이번 달 적립−사용, 최근 내역 20건을 봅니다(주는 단추는 없음).
- **연도별 분리** — 달란트 기록과 기준 모두 그 해(`year`) 자료로 저장되어, 연도를 바꾸면 그 해 것만 보입니다. 해가 바뀌면 지난해 기준을 이어 쓰고, 필요하면 그 해 기준을 따로 정합니다.
- **동기화** — `planSheets` · `talents` · `talentRules` 세 가지 자료를 같은 암호문 덩어리에 넣었습니다. 적립 기록 id 가 `tl-e:날짜:학생` 으로 정해져 있어 여러 기기에서 같은 날 눌러도 한 장으로 모입니다.
